# 使用系统原生弹窗

## 提示框
提示框是具有一个文本和按一个确定按钮的弹窗。  
在 EziApp 中使用 `alert('msg')` 即可显示系统原生提示框。  
该函数是同步的，返回值是 `undefined`。

## 确认框
确认框是具有一段文本、一个确定和一个取消按钮的弹窗。  
在 EziApp 中使用 `confirm('msg')` 即可显示系统原生确认框。  
该函数是同步的，根据用户选择，返回值是 `true` 或 `false`。

## 输入框
输入框是具有一段文本、一个输入字段，以及确定和取消按钮的弹窗。  
**注意：EziApp 目前不支持输入框功能**  
在 EziApp 中调用  `prompt('msg', 'defaultValue')` 函数始终会立即返回 `defaultValue`。
