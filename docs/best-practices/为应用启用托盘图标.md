# 为应用启用托盘图标

## 使用
使用以下示例代码启用托盘图标。  
托盘图标的右键菜单内置不可去除的“退出”和“显示主窗口”两个选项。
::: code-group

``` typescript [typescript]
import tray from "@eziapp-org/bridge/tray";
tray.show();

```

:::

## 配置右键菜单

你可以使用以下示例代码添加额外的右键菜单选项  
在 [托盘选项](/api-reference/tray) 中查看关于托盘图标的详细定义。

::: code-group

``` typescript [typescript]
tray.setContextMenu([
    {
        label: "测试啊",
        type: "text",
        checked: true,
        onClick: () => {
            alert("点击了测试啊");
        }
    }
]);
```

:::
