# 后端区分客户端版本
EziApp 会将 EziApp 版本、客户端名和客户端版本追加到所有由 EziApp 发起的请求的 userAgent 请求头中。  

::: code-group

``` text [userAgent 示例]
Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/144.0.0.0 Safari/537.36 Edg/144.0.0.0 EziApp/0.0.0 myProject/0.0.0
```

:::
在上文中 `EziApp/0.0.0` 是EziApp框架版本号，由当前使用的框架版本决定不可修改。`myProject/0.0.0` 客户端名和版本号，可在 `ezi.config.ts` 中修改。  

后端代码通过解析 userAgent 即可确认框架版本、客户端名和客户端版本。  
除此之外还可以识别出操作系统类型、操作系统版本、操作系统架构、Webview 版本号等信息。
