# AI Skills 介绍

为了帮助开发者更高效地使用 EziApp，我们提供了一系列专为 AI 编程助手（如 GitHub Copilot, Cursor, ChatGPT 等）设计的 Prompt 和规则文件。

这些配置文件可以让 AI 更好地理解 EziApp 的架构、API 和最佳实践，从而为你生成更准确的代码。

## 可用资源

- **[GitHub Copilot](/ai-skills/copilot-instructions)**: 适用于 `.github/copilot-instructions.md` 的配置。
- **[Cursor Rules](/ai-skills/cursor-rules)**: 适用于 `.cursorrules` 的配置。
- **[EziApp Prompt](/ai-skills/expert-prompt)**: 适用于直接与 ChatGPT/Claude 对话使用的 System Prompt。

## 如何使用

选择适合你开发工具的配置，复制内容到对应位置即可。

::: warning
这些提示词还需要 eziapp org 进一步改进。
:::
